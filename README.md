
# SubShare

## 📱 Descripción

**SubShare** es una plataforma web innovadora que facilita la gestión y el intercambio seguro de credenciales de suscripciones digitales (Netflix, Spotify, Disney+, etc.) entre amigos y familiares.

## ✨ Características principales

- **Almacenamiento seguro de credenciales**: Guarda contraseñas de suscripciones de forma protegida
- **Sistema de recordatorios automáticos**: Recibe alertas sobre fechas de pago para evitar retrasos
- **Permisos personalizables**: Controla quién puede acceder a cada credencial
- **Gestión de conflictos**: Previene malentendidos y confusiones entre usuarios

## 🎯 Motivación

SubShare surge de la necesidad real de resolver problemas comunes al compartir cuentas digitales:
- Pagos olvidados o retrasados
- Accesos no autorizados
- Desorganización entre usuarios
- Conflictos por responsabilidades

Nuestro objetivo es ofrecer una solución **sencilla, segura y organizada** para compartir suscripciones sin complicaciones.

## 🔒 Seguridad

La plataforma prioriza la confianza y la protección de datos mediante:
- Cifrado de credenciales
- Sistema de permisos granulares
- Control de acceso
